# TDX + RISC Zero Verification Tool

A Rust-based command-line tool for verifying Intel TDX quotes and RISC Zero receipts generated by the hello-world example.

## Features

- ✅ Parse and verify TDX quotes
- ✅ Verify RISC Zero zkVM receipts
- ✅ Check cryptographic binding between TDX and RISC Zero attestations
- ✅ Display detailed attestation information
- ✅ Color-coded output for easy reading
- ✅ Comprehensive verification instructions

## Installation

Build the tool:

```bash
cd verify-tdx
cargo build --release
```

## Usage

### Basic Verification

Verify all attestations in the default output directory:

```bash
cargo run --release
```

### Custom Output Directory

Specify a custom directory containing the attestation files:

```bash
cargo run --release -- --output-dir /path/to/tdx-output
```

### Detailed Information

Show detailed information including full hex dumps:

```bash
cargo run --release -- --detailed
```

### Verify TDX Quote Signature

Enable full TDX quote signature verification (requires valid Intel PCK certificates):

```bash
cargo run --release -- --verify-tdx
```

### Information Only Mode

Display information without performing verification:

```bash
cargo run --release -- --info-only
```

### All Options Combined

```bash
cargo run --release -- \
  --output-dir ../tdx-output \
  --verify-tdx \
  --detailed
```

## Command-Line Options

| Option | Description | Default |
|--------|-------------|---------|
| `-o, --output-dir <PATH>` | Path to tdx-output directory | `../tdx-output` |
| `--verify-tdx` | Verify TDX quote signature | `false` |
| `--verify-receipt` | Verify RISC Zero receipt | `true` |
| `--verify-binding` | Verify binding between attestations | `true` |
| `-d, --detailed` | Display detailed information | `false` |
| `--info-only` | Skip verification, only show info | `false` |
| `-h, --help` | Print help information | - |

## What It Verifies

### 1. TDX Report
- File exists and is 1024 bytes
- Structure matches TDX report format
- Displays REPORTDATA (first 64 bytes)

### 2. TDX Quote
- Parse quote structure
- Display header, body, and measurements
- Verify signature (if `--verify-tdx` enabled)
- Check certificate chain
- Extract REPORTDATA for binding verification

### 3. RISC Zero Receipt
- Check receipt JSON file
- Calculate receipt hash (if binary available)
- Display receipt metadata

### 4. Attestation Binding
- Compare TDX REPORTDATA with receipt hash
- Verify cryptographic binding
- Confirm both attestations are linked

## Dependencies

- **tdx-quote** (0.0.4) - TDX quote parsing and verification
- **risc0-zkvm** - RISC Zero receipt verification
- **clap** - Command-line argument parsing
- **anyhow** - Error handling
- **hex** - Hex encoding/decoding
- **serde_json** - JSON parsing
- **sha2** - SHA-256 hashing
- **colored** - Colored terminal output

## Integration with run-in-tdx.sh

To enable full binding verification:

1. Use the enhanced main.rs:
```bash
cp ../src/main-tdx.rs.example ../src/main.rs
```

2. Run the TDX execution:
```bash
../run-in-tdx.sh
```

3. Verify with this tool:
```bash
cargo run --release
```

## Testing Without TDX Hardware

The tool will gracefully handle missing files and provide informative messages. You can test the parsing logic with mock data:

```bash
# Create test directory
mkdir -p test-output

# Copy test files (if available)
cp test-data/* test-output/

# Run verification
cargo run --release -- --output-dir test-output --info-only
```

## Troubleshooting

### "Output directory not found"
Run `../run-in-tdx.sh` first to generate attestation files.

### "Quote verification failed"
This is expected without valid Intel PCK certificates. The quote structure will still be parsed and displayed.

### "Binary receipt not found"
Use the enhanced `src/main-tdx.rs.example` to export binary receipts.

### "Binding not found"
The receipt hash must be included in TDX REPORTDATA during generation. Modify `run-in-tdx.sh` to implement binding.
